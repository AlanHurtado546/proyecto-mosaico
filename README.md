# Proyecto Mosaico de Alturas

## Hipotesis

Si se desarrolla una aplicacion web utilizando Python y FastAPI que permita
representar valores numericos mediante una matriz de colores, entonces sera
posible visualizar de manera sencilla los valores maximos, minimos y las
diferencias de altura dentro de un mosaico.

El programa permite generar valores aleatorios, modificar una celda mediante
las coordenadas X y Y, asignar un valor Z y representar cada valor mediante
diferentes colores.
